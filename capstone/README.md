# Strategic Customer Deployment — Capstone

**Created by School of AI**

Northstar Services asks: **"Use AI to reduce support workload and improve response quality."** The request is intentionally vague.

You are the FDE. Deliver the engagement through:
1. discovery
2. workflow mapping and baseline
3. hero-workflow scope
4. architecture
5. working vertical slice
6. customer-specific evaluation
7. security/deployment readiness
8. observability/runbook
9. pilot/adoption plan
10. ROI/value proof
11. executive readout
12. handoff and reusable field feedback

## Required vertical slice
User submits support issue → intent is understood → relevant knowledge retrieved → grounded answer with citations → customer/ticket context lookup → write action approval gate → trace/audit event.

## Required demo evidence
- happy path
- missing/poor evidence
- dependency failure
- unauthorized/high-risk action blocked
- evaluation results
- measurable workflow value
- handoff recommendation
