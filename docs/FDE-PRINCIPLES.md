# FDE Principles

**Created by School of AI**

1. Start with workflow.
2. Measure baseline.
3. Solve smallest high-value problem first.
4. Prototype to retire risk.
5. Build vertical slices.
6. Protect scope.
7. Keep customers in the loop.
8. Evaluate on customer-specific cases.
9. Design path to production early.
10. Measure adoption.
11. Quantify value.
12. Leave reusable patterns.
13. Feed field learning to product.
14. Communicate clearly under ambiguity.
15. Own outcome end to end.
