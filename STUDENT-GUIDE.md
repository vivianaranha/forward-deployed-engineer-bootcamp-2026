## FDE learning loop
**Ask → Observe → Frame → Scope → Build → Demo → Measure → Iterate → Document**

Before proposing AI, answer: who has the problem, what the workflow is today, what the baseline is, what systems/data are involved, what can kill the project, and how value will be proved quickly.

Maintain an engagement notebook with discovery, workflow map, requirements, assumptions, decisions, risks, metrics, demo feedback, evals, adoption, ROI and handoff notes.
