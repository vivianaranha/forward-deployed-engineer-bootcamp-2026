## Core FDE outcomes
Students learn discovery, workflow mapping, technical scoping, architecture, rapid prototyping, AI/RAG/agents/MCP, enterprise integration, evaluation, security, deployment, observability, adoption, ROI, executive communication, handoff and reusable field patterns.

## Principle
The goal is not merely: **"We shipped the feature."**

The goal is: **"The customer workflow improved, we can measure it, the system is supportable, and the pattern can be reused."**
