# Build Guide — Technical Scope & Success Plan

**Created by School of AI**

1. State the customer and workflow.
2. Define the current baseline.
3. Identify the highest-value pain point.
4. Define measurable success.
5. Write the smallest useful scope.
6. List integrations/data/dependencies.
7. Identify the biggest technical unknown.
8. Build the thinnest proof that resolves that unknown.
9. Add one unhappy-path test.
10. Validate with a simulated customer persona.
11. Record feedback.
12. Update scope or architecture if evidence changes.
13. Estimate value.
14. Create a next-step recommendation.
15. Prepare a two-minute customer demo.
