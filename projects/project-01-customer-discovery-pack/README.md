# Project 01 — Customer Discovery Pack

**Created by School of AI**

**Level:** Beginner  
**Skills:** discovery, workflow mapping, stakeholder analysis

## Customer outcome
Turn a vague customer request into structured discovery artifacts.

## FDE deliverables
- customer problem statement
- current workflow and baseline
- explicit scope
- architecture
- working proof or delivery artifact
- test/evaluation evidence
- risk register
- customer demo
- value hypothesis
- next-step recommendation

Do not add complexity unless it retires a meaningful customer or delivery risk.
